# 怎么量才不会自欺欺人

解锁类项目最容易出现的假象是：**写了一堆中文Feel的数字，但没有一个能经受复现。**
这一页记录我们踩过的坑和最后的量法。

## 两个不同层面的量，别混为一谈

| 层面 | 工具 | 说明 |
|---|---|---|
| **硬件层**：这块 silicon 现在能不能算满 | `bench/mma_peak.cu` | 纯寄存器 HMMA，不刷固件、几乎不吃显存 |
| **应用层**：真实工作负载快了多少 | `bench/run_bench.py` | 固定 prompt 打引擎 API，解析引擎日志 |

**只有硬件层过了，才有必要接着测应用层。** 反过来说，应用层没涨，不代表硬件层没生效 ——
这两件事可以完全独立（我们这次就是：硬件 +94%，应用 +8%）。

## 硬件层：`mma_peak.cu`

```
nvcc -arch=sm_75 -O2 mma_peak.cu -o mma_peak.exe
mma_peak.exe 0     # 指定卡
mma_peak.exe 1
```

三个关键点：

1. **Turing 只有 `mma.sync.aligned.m16n8k8`**。写成 Ampere 的 `m16n8k16` 编译不过。
   每个 mma 的浮点数是 `2048`，别照抄 sm_80 例子里的 `4096`。
2. **必须在纯寄存器里做累加**，不要放 shared memory 或 global —— 否则测的是访存不是算力。
3. 它几乎不占显存，所以**可以在服务占满显存时照跑**（我们就是在两卡各 21 GB 被占的情况下测的）。

判据是**比值** `FP16→FP32 累加 / FP16→FP16 累加`：

- 原厂砍半：**0.50 左右**
- 满速：**趋近 1.0**（本机 0.964 / 0.980）

用比值而不是绝对 TFLOPS，是因为绝对值受当前频率、功耗墙、温度影响；
比值是两个基准跑出来的，把这些变量都约掉了。

## 应用层：固定 prompt 对照，而不是翻历史日志

### 坑：日志里大多数条目是 KV 复用的

引擎日志长这样：

```
strata serve: prompt 146260 tokens = 145977 reused + 283 read in 1588 ms (178.2 tok/s), ...
```

`reused` 才是 145977，真正要算的 `read` 只有 283 个 token。拿这种条目的 tok/s 去对比是没意义的。

### 坑：历史基线会骗人

我们也试过直接和历史日志比。按冷读尺寸分桶后：

| 冷读尺寸 | 样本数 | 中位 |
|---|---|---|
| 20K~45K | 189 | 1295 tok/s |
| 45K~60K | 60 | 1681 tok/s |
| 60K~75K | 111 | 1867 tok/s |
| 80K~95K | 59 | 1889 tok/s |

样本极其分散（同一档里 729 到 2025 都有），因为混了启动预热、不同配置、不同 prompt 内容。
**结论：历史日志只配拿来粗略兜底，不能拿来出结论。**

### 正确做法

`bench/run_bench.py` 生成 **3 条确定性 prompt**（各约 52,083 token，内容不同所以必然冷读），
跑完从引擎日志解析每条的 `read` / `prefill tok/s`。同一批 prompt 在解锁态和锁定态各跑一遍，才可比。

```bat
set STRATA_LOG=<你的引擎日志路径>
python bench\run_bench.py --gen            :: 生成 prompt（幂等）
python bench\run_bench.py --tag unlocked
:: 重启回原厂态后
python bench\run_bench.py --tag locked
```

本机解锁态的结果（3 条）：

```
1953.3 / 1973.1 / 1929.6 tok/s  -> 均值 1952.0
```

离散度不到 3%，所以这个量是能用的。

> 锁定态那半边一定要**真重启回去跑**。我们当时为了省两次重启没做，
> 最后只能用历史数据估一个区间（+8%~13%），精度远不如受控对照。
> 别学我们 —— 数据差一倍，结论可信度天差地别。

## 报数字时的三条规矩

1. **给分布，不给单点**。三条以上的样本再谈结论。
2. **说清条件**。上下文长度、prompt 长度、是否复用、当前频率/功耗墙都要写。
3. **把负面结果一起报**。decode 没变就是没变，不要只挑好看的说。
